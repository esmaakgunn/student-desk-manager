# Student Desk Manager - Öğrenci Görev Takip Sistemi

## Proje Hakkında

Bu proje, Güncel Yazılım Geliştirme Süreçleri ve DevOps dersi kapsamında bireysel olarak geliştirilmiştir.

## Problem Tanımı

Öğrenciler, yoğun ders programları nedeniyle ödevlerini ve günlük görevlerini takip etmekte zorlanabilmektedir. Bu uygulama, görevlerin tek bir platform üzerinden yönetilmesini amaçlamaktadır.

## Hedef Kullanıcılar

Ödevlerini ve günlük sorumluluklarını düzenli olarak takip etmek isteyen öğrenciler.

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- Git ve GitHub
- GitHub Projects

## Proje Yönetimi

Proje, Kanban yöntemi kullanılarak yönetilmiştir.

[GitHub Projects - Kanban Panosu](https://github.com/users/esmaakgunn/projects/1)

Panoda Yapılacak, Devam Ediyor ve Tamamlandı olmak üzere üç sütun bulunmaktadır. Beş görev planlanmış ve iki görev geliştirilerek test edilmiştir.

## Proje Özellikleri

- [x] Yeni görev ekleme
- [x] Görevi tamamlandı olarak işaretleme
- [ ] Görev silme
- [ ] Görevleri filtreleme
- [ ] Görevleri tarayıcıda kaydetme

## Projeyi Çalıştırma

1. GitHub deposundaki Code butonuna tıklayın.
2. Download ZIP seçeneğiyle projeyi indirin.
3. ZIP dosyasını bir klasöre çıkarın.
4. index.html dosyasını internet tarayıcısında açın.

Ekstra kurulum, sunucu veya veritabanı gerekmemektedir.

## Geliştirilen Özelliklerin Test Edilmesi

### Özellik 1: Yeni Görev Ekleme

1. Görev adı alanına Matematik ödevini yap yazın.
2. Ekle butonuna basın.
3. Görevin listede göründüğünü kontrol edin.
4. Görev giriş alanının temizlendiğini doğrulayın.
5. Boş veya yalnızca boşluk içeren bir görev eklemeyi deneyin.
6. Boş görevin listeye eklenmediğini kontrol edin.

- [Görev Kartı #1](https://github.com/esmaakgunn/student-desk-manager/issues/1)
- [İlgili Commit](https://github.com/esmaakgunn/student-desk-manager/commit/9f0a07e)

### Özellik 2: Görevi Tamamlandı Olarak İşaretleme

1. Uygulamaya iki farklı görev ekleyin.
2. İlk görevin yanındaki kutucuğu işaretleyin.
3. Görev metninin üzerinin çizildiğini kontrol edin.
4. Diğer görevin etkilenmediğini doğrulayın.
5. İşareti kaldırarak görevin eski görünümüne döndüğünü kontrol edin.

- [Görev Kartı #2](https://github.com/esmaakgunn/student-desk-manager/issues/2)
- [İlgili Commit](https://github.com/esmaakgunn/student-desk-manager/commit/e890ccf)

## Proje Durumu

Ders yönergesi kapsamında planlanan beş görevden ikisi geliştirilmiş ve kabul kriterleri doğrulanmıştır. Kalan üç görev gelecekteki geliştirmeler için planlanmıştır.

Kalıcı kayıt özelliği henüz geliştirilmediğinden sayfa yenilendiğinde görevler kaybolmaktadır.
