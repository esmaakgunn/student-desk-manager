# Student Desk Manager - Öğrenci Görev Takip Sistemi

## Proje Hakkında
Bu proje, Güncel Yazılım Geliştirme Süreçleri ve DevOps dersi kapsamında bireysel olarak geliştirilmektedir.

## Problem Tanımı
Öğrenciler, yoğun ders programları nedeniyle ödevlerini ve günlük görevlerini takip etmekte zorlanabilmektedir. Bu uygulama, görevlerin tek bir platform üzerinden yönetilmesini amaçlamaktadır.

## Hedef Kullanıcılar
Ödevlerini ve günlük sorumluluklarını düzenli olarak takip etmek isteyen öğrenciler. Daha verimli ders çalışabilmeleri için geliştirildi.

## Kullanılacak Teknolojiler
- HTML5
- CSS3
- JavaScript
- Git ve GitHub
- GitHub Projects

## Planlanan Özellikler
- [ ] Yeni görev ekleme
- [ ] Görevi tamamlandı olarak işaretleme
- [ ] Görev silme
- [ ] Görevleri filtreleme
- [ ] Görevleri tarayıcıda kaydetme

## Proje Yönetimi
Proje, Kanban yöntemi kullanılarak GitHub Projects üzerinden yönetilecektir.

## Proje Durumu
Geliştirme aşamasındadır.
